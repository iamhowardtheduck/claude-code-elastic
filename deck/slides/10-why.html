Why it's awesome

Built like a real Elastic integration. Not a log dump.

Zero-touch collection

No changes to Claude Code, no proxy, no API key interception. If Elastic Agent is on the machine, you have coverage.

Open standards

ECS plus OpenTelemetry gen_ai.*, so it correlates with the EDR, network and OTel data you already collect.

Costs you can trust

Keeps Anthropic's split of uncached input, cache reads and cache writes, and deduplicates on gen_ai.response.id.

No duplicates

event.id becomes the document _id, so resumed sessions never double-count.

Fail-open ML

Off by default, one toggle to enable, never blocks ingest. Its health has its own dashboard.

Complements OTel

Runs alongside Elastic's claude_code OTel integration: that one is telemetry, this one is what was said and done.
