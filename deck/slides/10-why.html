Why it's awesome

Built like a real Elastic integration,
not a log dump.

Zero-touch collection

No changes to Claude Code, no proxy, no API key interception. If Elastic Agent is on the machine, you have coverage.

Open standards

ECS plus OpenTelemetry gen_ai.*, so it correlates with EDR, network and OTel data you already collect.

Costs you can trust

Keeps Anthropic's raw split of uncached input, cache reads and cache writes, so spend is priced correctly. Deduplicates on gen_ai.response.id.

No duplicates

event.id becomes the document _id, so resumed sessions never double-count.

Fail-open ML

Inference is off by default, enabled with a single toggle, and never blocks ingest. You can watch its health on its own dashboard.

Complements OTel

Runs alongside Elastic's official claude_code OTel integration. That one gives you telemetry; this one gives you what was actually said and done.
