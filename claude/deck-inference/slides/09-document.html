categories

Every label that crossed its threshold, as group:key. Dashboards and rules filter on this one keyword list.

flagged

True when any flagging category fired: here the secret. The detection rules in extras/ start from it.

scores

Raw probabilities from every model, kept below threshold too, for hunting and re-tuning.

semantic · secrets

The nearest threat concept, and the redaction findings copied in, so one object holds the verdict.

inference
