What it contains

Three data streams. One package.

Transcripts, desktop and MCP logs, and the health of the ML pipeline that enriches them.

claude_code_transcripts.transcript

Session transcripts

One document per conversation line from the CLI, the VS Code and JetBrains extensions, the Desktop Code tab and Cowork. Covers prompts, responses, thinking, tool calls and results, subagents, and token usage.

200+ fieldsevent.id = _id
claude_code_transcripts.desktop_log

Desktop and MCP logs

main.log, mcp.log and mcp-server-*.log on Windows and macOS. Parses MCP requests, responses and notifications into server, method and outcome.

claude_code_transcripts.inference_stats · optional

ML inference stats

CEL input that polls trained-model and ingest-pipeline stats every minute, so you can tell whether inference is keeping up.
