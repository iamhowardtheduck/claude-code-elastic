# Inference and redaction deck (Claude Code and Gemini CLI)

> Covers Claude Code and Gemini CLI together. `../claude/deck-inference/` covers Claude Code only, and [`deck-inference/` in gemini-cli-elastic](https://github.com/iamhowardtheduck/gemini-cli-elastic/tree/main/deck-inference) covers Gemini CLI only.

A 13-slide [fslides](https://github.com/fslides/fslides) deck, in the elastic-web kit, on everything the Claude Code Transcripts and Gemini CLI Transcripts ingest pipelines do to a prompt before it is stored. One design serves both integrations: the same secret redaction (19 detector types), the same EIS embedding and semantic threat flags, the same five single-pass classifiers and five zero-shot passes. A dedicated slide lists the few Gemini CLI differences (field prefix, redacted fields including `thoughts`, the zero-shot interaction label and the NER ignore list). It also covers the classified document and where the inference time goes.

- Slides: https://iamhowardtheduck.github.io/claude-code-elastic/inference/
- PDF: [`docs/claude-code-transcripts-inference.pdf`](../docs/claude-code-transcripts-inference.pdf)

## Edit it

```bash
cd deck-inference
npm install
npx fslides serve    # http://localhost:30002
npx fslides pdf
```

Sources: `packages/claude_code_transcripts/data_stream/transcript/elasticsearch/ingest_pipeline/` and [`packages/gemini_cli_transcripts/…/ingest_pipeline/`](https://github.com/iamhowardtheduck/gemini-cli-elastic/tree/main/packages/gemini_cli_transcripts/data_stream/transcript/elasticsearch/ingest_pipeline) in gemini-cli-elastic (`default.yml`, `inference.yml`, `classify.yml`; the Gemini CLI copies are generated by `tools/port_gemini.py`), `docs/inference-models.md` and `docs/inference-tuning.md`. Example prompts and documents are synthetic, from `tools/loadgen.py` on the Elastic Cloud test deployment; per-step timings are from the Claude Code load test.
